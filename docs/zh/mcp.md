# 模型上下文协议（MCP）

Agora 可以作为 MCP 主机和客户端，通过 **Streamable HTTP** 将助手连接到远程 MCP 服务器；旧版 HTTP+SSE 服务器可自动回退兼容。

## 添加服务器

1. 打开 **设置 → 工具 → MCP**。
2. 启用 MCP，选择 **添加 MCP 服务器**。
3. 输入服务器名称和完整端点 URL，通常以 `/mcp` 结尾。
4. 除非服务器明确要求旧版 SSE，否则保持 **自动** 传输模式。
5. 如端点需要认证，可填写 Bearer 令牌/自定义请求头，或启用 OAuth 2.1，然后选择 **测试连接**。

也可以粘贴 Claude Desktop/Cursor 风格的 `mcpServers` JSON 批量导入远程 HTTP 服务器；Android 不支持的 stdio 项会被跳过。

连接测试会执行 MCP 初始化握手，并显示服务器实现以及工具、资源和提示词数量。

## 已支持能力

- MCP 2025-11-25 生命周期与能力协商
- Streamable HTTP（JSON、内联 SSE、会话、重连）及旧版 SSE 回退
- 持续连接状态、断线指数退避重连与配置变化自动协调
- 工具、资源、资源模板和提示词的分页发现
- 工具调用及结构化、文本、图像、音频、资源链接和嵌入资源结果
- 通过助手内置的 MCP 桥接工具读取资源和获取提示词
- Bearer 令牌、自定义请求头，以及 OAuth 2.1（受保护资源/授权服务器发现、PKCE、动态客户端注册和刷新令牌）
- 按服务器和按工具启用、请求超时、能力暴露与逐工具调用确认

Agora 会自动给远程工具添加服务器命名空间，避免同名工具冲突。同步后的工具清单和开关会持久保存，服务器更新描述或 Schema 时不会覆盖你的启用与审批选择。转发到模型供应商时，工具参数仍保持完整 JSON Schema。

## 安全

远程 MCP 服务器可以执行操作，也可能返回不可信指令。除非你信任当前环境中的服务器，否则请保持 **每次远程工具调用前确认** 开启。凭据会在本地设置中加密保存；只有明确选择导出 API 密钥时才会包含在备份中。

本地开发端点可以使用 `http://`；通过不可信网络连接服务器时应使用 HTTPS。

!!! note
    Android 应用无法在所有发行 flavor 中提供通用的桌面进程环境，因此此设置页支持远程 HTTP 传输，不负责通过 stdio 启动 MCP 服务器。
